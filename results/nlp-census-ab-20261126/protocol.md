# Frozen comparison protocol

Population: the 90 open E2/E3/E4 cells in commit 8b5ac86, 39 projects, cutoff 2026-11-13. Count latitude and longitude as two Census cells but as one evidence search. Coalesce deposit text/code and stage code/category within each project. The original coverage denominator is 3,034.

The full 39-project cohort is held out from NLP development. Real development controls are the separate Lynas/Mt Weld and Northern Minerals/Browns Range project and issuer-report families; code tests use invented documents. Classify publisher families as a whole for separation from development. Use only explicitly identified control originals with their own family marker and no target alias in the full native text for development. Quarantine any other PDF mentioning either development issuer or project anywhere in native text, including mixed government reports. All remaining eligible originals are evaluation-only. Group equal bytes across source keys by SHA. List the split and exclusions before scoring. No tuning on target documents, labels or ranked results. BM25 document frequencies are computed on the retrieval index at query time. Existing Phase 22 rules and historical adjudications predate this experiment; historical familiarity is distinct from the NLP holdout.

Use a common library of SHA-verified, within-cutoff, explicitly admitted PDF editions from Phase 22. Use the same project name, field and maximum five physical pages per query. A reads the actual pre-existing output locators for that project/field. B keeps those locators and fills remaining slots with fixed BM25 (k1=1.2, b=0.75); its input contains no review notes, gold locations or expected values. Report empty queues, pages returned and review burden. A page is a paired document SHA and physical page number.

Freeze reference judgments before scoring, independently of predictions. A reference can support reviewing the field even when it explains why the value must remain blank. Primary hit@5 counts a query with at least one matching physical page among queries with at least one in-frame judged contextual or sufficient page. Also report field-cell counts, all-target denominators, per-family results, inaccessible/quarantined references, unknowns, and sufficient-only hit rate when measurable. Multiple correct pages for the same query count once. For a grouped query, report each cell separately as well; evidence for one column need not support another. Unknowns do not become negatives. Separate paired additions/losses from cases hit by both arms. No claim of exhaustive precision from partial page labels.

Review the union of candidates for possible admissions with provenance and keep dispositions per query. A context-only match, project-name match, map, tenement schedule, or isolated code does not by itself authorize a Census value. If a new claim is supported, send it through the existing acceptance rules and independently replay each arm's accepted inputs. Count a wrong admission only on a newly changed production cell, with an explicit reference check. With no submissions, zero erroneously admitted cells has no precision denominator. Compare all 4,743 cells and the fixed denominator on the output of the original all command. Compare module imports against the pinned branch graph. No new production import or acquisition entry point.

Human review timing uses an optional isolated, counterbalanced two-reviewer packet. Only completed stopwatch sessions are measured; unobserved human time and any empty denominator are NULL. Do not substitute execution time, token usage or model review time.
