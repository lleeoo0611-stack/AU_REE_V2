# 澳洲稀土資料的本體設計依據

比較的單位是一筆有出處的觀測。例如「某專案在某次資源聲明中、指定門檻及物料基準下的全礦噸數」。同一個專案可以有多個時點、物料及範圍的觀測。「可比較」必須指明所要回答的問題。

| 設計背景 | 在澳洲稀土資料庫中要區分什麼 | 可採用的外部依據 |
|---|---|---|
| 礦產資源申報 | 勘探結果、礦產資源量與礦石儲量；資源分類、選定聲明、有效日期、估算範圍及門檻。兩份跨專案聲明可來自不同日期，但要符合相同截日，且各自的數值須來自各自選定的估算。 | [JORC Code 2012，尤其 Table 1 第 3 節](https://www.jorc.org/docs/JORC_code_2012.pdf)；保留原件實際採用的版本。 |
| 地質與礦業實體 | 礦物產地、礦床、礦山、採礦活動、商品與專案各有自己的身分。同一資源聲明或礦體可以出現在不同公告；重複刊載不增加獨立樣本數。 | [IUGS CGI EarthResourceML](https://cgi-iugs.org/earthresourceml/) 提供礦產與礦業活動的交換模型。另以本地關係表達公司宣告的專案範圍。 |
| 計量、地球化學與選礦 | 將量別、單位、分析物、元素或氧化物、物料及分母分欄；視用途記錄氧化物籃子、乾濕基與篩分粒徑。ppm 可換成質量百分比，但還要確認所量的是相同化合物，且分母相容。 | [QUDT 的量別、單位與維度](https://qudt.org/)；化學組成及製樣條件以報告的實際定義為準。 |
| 術語與證據管理 | 區分同義、近義及上下位概念。例如探勘模型與已證實礦床可共用主題詞，但證據層級必須保留。為每次映射記錄原件指紋、頁碼、版本、轉換與判定原因。資料缺一項時，返回缺少的條件，保留重開途徑。 | [W3C SKOS](https://www.w3.org/TR/skos-reference/) 可表達詞彙對照，[PROV-O](https://www.w3.org/TR/prov-o/) 可描述來源與衍生，[SHACL](https://www.w3.org/TR/shacl/) 可描述驗證條件。 |

本輪測試把選定資源聲明當作輸入，以本地語意規則執行配對。表內的國際標準是模型設計參照；本輪沒有進行整個資料庫的 RDF 轉換、外部詞彙認證或 SHACL 合規驗證。

## 權重所能回答的問題

CRITIC 估計一項指標在指定比較群體內提供多少統計區辨力。對已對齊好壞方向、經縮放的指標，先計算標準差，再乘上該指標與其他指標的相關衝突總和，最後正規化為總和一。當只有兩個非常數指標且相關係數小於一，兩者的衝突項相同，權重比例就取決於縮放後的標準差。[Diakoulaki、Mavrotas 與 Papayannakis 的 CRITIC 原始論文](https://doi.org/10.1016/0305-0548(94)00059-H)

本研究先固定「哪些觀測有資格比較」和「各指標越大越好或越小越好」，然後才估權。等權提供基準，熵權檢查結果是否過度取決於少數極端值，逐案留出則顯示單一專案對估權的影響。領域內估權仍保留原有領域比例；跨域直接估權可檢查拿掉這項偏好後的結果。權重大小不能用來推斷資源量或交通可及性在政策上應占多少。[OECD／歐盟 JRC 複合指標方法手冊](https://www.oecd.org/content/dam/oecd/en/publications/reports/2008/08/handbook-on-constructing-composite-indicators-methodology-and-user-guide_g1gh9301/9789264043466-en.pdf)
