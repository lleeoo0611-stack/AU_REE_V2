# robots 404／410 修正與重跑

本次依分支審查修正 robots.txt 的回應處理，PR #10 保持 Draft，不轉 Ready、不 merge。前次 93f3aac 的報告與數據保留在上層目錄；本目錄另外保存重跑證據，尚待乾淨 CI 的實測結果。

## 修正範圍

- 僅 robots.txt 回 404／410 時視為沒有規則，允許繼續請求原件；同次建置快取此結果，不重複取得 robots。
- robots.txt 回 401／403／429 仍停止該 host；這是本專案保守政策。
- robots.txt 回 5xx 或連線失敗仍全部禁止；沿用既有重試上限及網路失效判準。
- 主要文件回 404／410 仍停止該 host，沒有放行一般文件的 4xx。
- www 首次 NOT_PDF 後仍不再請求，包含 robots；同 SHA、host 間隔、redirect、請求額度、候選額度與搜尋關閉均維持。

規範依據：[RFC 9309 §2.3.1.3／§2.3.1.4](https://www.rfc-editor.org/rfc/rfc9309.html#section-2.3.1.3)。規範容許 4xx 時存取；本次僅放行 404／410，並未宣稱規範要求放行所有 4xx。
