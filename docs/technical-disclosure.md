# Phase 19 — 技術資訊揭露透明度 v1

本版正式取代目前研究的 T1；歷史設定與輸出不追溯改名。T1 現在衡量文件限定的資訊透明度，
不是技術可行性、效率、成功機率、產品合規或 JORC 認證。JORC Code 2012 Table 1 只提供整理骨架；
以下七項分類、二分條件與等權計分均為本研究操作化設計。

## 最低條件（全部子條件須成立）

|項目|必要內容|不充分的例子|
|---|---|---|
|TD1 樣本來源、採樣、前處理|指出採樣礦區／地質域或明確樣本集合；說明採樣／組樣方式；交代相關試驗給料的前處理。不能用資源鑽探的一般制樣冒充另一組選冶樣本的方法。|僅「代表性樣本」、僅鑽孔位置|
|TD2 路線與選擇依據|說明相連的主要處理步驟及終點；交代選擇依據、礦物學／比較試驗依據或尚未選定路線的具體原因。|只有 flowsheet 標題或「低成本流程」|
|TD3 回收及數值依據|說明元素／氧化物基準、給料、回收產品／加工邊界，以及數值或明確未建立回收值的原因；說明數據來自何種試驗、計算或假設。未測試且具體交代這些範圍及原因亦可達標。|孤立的「回收率95%」|
|TD4 處理投入|**藥劑、能源、水三類各自**交代種類／需求或用量、適用處理範圍及資料依據；未量化時，各類須明列尚未評估／不適用及具體原因。三類全達標才得1分，不拆分、不任選一類。酸濃度不是酸耗，但可以是明確標示的試驗投入條件。|「低酸耗」；只揭露酸耗；只說再生能源與循環水|
|TD5 產品與限制|指出產品性質／形態；規格數據或規格尚未確立的具體原因；指出相關有害元素／雜質及處置／限制，或交代其尚未驗證的範圍及原因。|「高純度可銷售產品」、僅聲稱低放射性|
|TD6 尺度與資料性質|交代試驗／設計尺度及數據是實測、模型或假設；尚未實驗須具體交代目前工作的類型、範圍與限制。無成熟度加分。|僅 PFS／DFS 標題；「進一步試驗」|
|TD7 代表性及外推|交代所代表的樣本／地質／資源範圍，說明選擇／覆蓋依據及外推限制，或明說不能外推並提供具體理由。原句「representative」不等於完成代表性查核。|只有「代表性複合樣」|

必要內容可分散於相同群組多份文件。每個得分子條件必須有來源原句與明確判讀理由；
來源文字命中、既有欄位有值或自動抽取均不是充分判讀。
相同具體敘述可支持不同的可辨認事實，但不可用同一模糊敘述填滿多項。

## 四種狀態與分數

- `DISCLOSED`：各子條件有具體揭露，1。
- `EXPLICIT_UNKNOWN`：部分或全部內容明確未建立／未進行／不適用，**每個未建立的子條件**均有範圍與具體理由，其餘子條件亦達標，1。
- `INSUFFICIENT`：完成下述限定文件查核，仍欠缺必要子條件，0。並不代表技術差或外部絕無資料。
- `UNVERIFIABLE`：來源不可讀、身分或範圍不明、查核未完成、重大矛盾無法判定，NULL。

固定分母7；已確認得分 N/7×100，U個未知時可能分數為[N/7,(N+U)/7]×100。
U>0時點分數保持NULL；下界不是補零的已知分數。未知不抽樣、不取中點。

全文檢索七項詞族及JORC相關章節，逐一判讀命中、相鄰方法／表頭／腳註及適用範圍，

此查核是研究者（本次由代理執行）的來源限定內容編碼，不是獨立雙人標註或人工簽核。

評估對象為原31群組所限定的範圍。可包含該範圍有日期的技術研究歷程；不同方案及

資料足夠的單一項目可以先計分，不受同案其他項目的未知阻塞。

## MCDA 與研究解讀

T1=本版透明度；回收、投入、產品等原始數據繼續保留作補充研究。
承接現有三情境Technical權重10%／20%／10%，不增加總權重。
比較T權重0、原權重、5%、10%、20%、30%；其餘構面按原相對比例乘以(1−T)/(1−原T)。
不逐案重配權。固定效用錨點、SAW／PROMETHEE II／TOPSIS沿用既有引擎。
未取得的非Technical準則亦保留未知域，不用透明度代替它們。
區間排名是保守可能集合，並列保留；不是信賴區間或名次機率。
另以既有可觀測共同面板比較有／無T，並對Development重疊作描述與移除D壓力測試。
正式C1的六項Gate及核定狀態不由此自動改變。
