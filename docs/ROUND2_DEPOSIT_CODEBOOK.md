# 第二輪礦床型態代碼

`iac` 代碼在本表包含「離子型未確認的黏土／風化殼型」，以 provenance 的 `qualifier` 區分。下游 MCDA 若要只取確認離子型，以 qualifier 篩選。代碼並不證明可交換離子比例或回收率。

本輪僅新增空白代碼，原文、既有代碼及其 provenance 不變。三個潛力案加 `SPECULATIVE_DEPOSIT_STYLE`；Norwest Arunta West 的 suggests／subject to amendment 不視為確認離子型。既有 SOURCE_REPORTED 原文沒有頁碼時，locator 明確指向凍結的來源綁定欄位與 SHA，不虛構 PDF 頁碼。

G4 依封存原件：Mt Stirling 所選 Yttria 資源量位於腐岩層（p25）；Burracoppin REE 富集於高嶺土帶（p10）；Wudinna 所選 MRE 的 Pidinga／Garford 描述為黏土／有機物吸附。這三案為 iac 並帶 IONIC_NOT_CONFIRMED。Greater Brothers 的肯定主體描述只適用 Jupiter 子案，不外推父案；Perenjori 古河道礦物載體未明，兩案留白。
