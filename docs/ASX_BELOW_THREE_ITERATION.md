# Complete-round stopping rule

Continue the same isolated acquisition branch from the published current projection. Freeze the starting project IDs, 53-column CSV hash and commit before each series. `BELOW_THREE_COMPLETE_ROUND` stops only when a **complete** documented round adds fewer than three verified cells. `ZERO_NEW_VERIFIED_CELLS` and `LEGACY_BELOW_THREE` retain their historical behavior for replay.

Each round must search both the candidate queue (including unresolved external names) and the table gaps, with all 53 columns in scope. Prioritize resource tonnage, compatible TREO grade, individual oxide composition and engineering annual output. Capture permitted public originals and receipts, review project identity, same-code/name aliases, resource or study scope, units, material basis and effective dates. Only source-reviewed ledger changes can enter the exporter. An external CSV supplies leads, never validated companies, tickers or scientific values.

Replay the full source ledgers against the read-only Census, extend the identity column, run relevant tests, then independently rebuild again. `tools/package_coverage_cycle.py` checks matching CSV hashes, complete provenance/missing diagnostics, unchanged Census hash, passing JUnit output and matching ledger snapshots before publication. Cell withdrawals require a separate review and prevent publication through this path.

Count existing-project blank fills separately from new-project cells; show scientific cells independently. Changed values and numeric reformatting are not new fills. New-project identity cells do count toward the requested total-cell threshold. The comparison cohort is the starting project set, not an older research snapshot.

For this policy, missing dual-track records, unresolved downloads/reviews, an incomplete all-column declaration or failed source/test/rebuild checks yield `INCOMPLETE`, even with zero, one or two new cells. A timeout, HTTP restriction, exhausted search allowance or interrupted round is never evidence of zero yield. Record the blocker and the next acquisition/review action; do not declare STOP. STOP concerns only the documented round and is not a national-completeness or absence claim.

Use `tools/review_coverage_cycle.py --before ... --after ... --manifest ... --out ...` for the audit and the packaging tool for validated publication. Set `stopping_policy` explicitly to `BELOW_THREE_COMPLETE_ROUND`; include all column names in `search_scope.columns`, the two completed tracks with query/disposition records, and an explicit `unresolved_acquisition_actions` list. This audit does not independently perform or prove web search and scientific review; those operations and their receipts remain required.

Resource units remain fail-closed. The `(000)` heading under a literal `Tonnes` column can supply kilotonnes of bulk ore, converted to Mt. It cannot supply million tonnes, a grade or contained REO. Monazite Equivalent, TREO, TREO+Y, elemental ppm, oxide ppm, concentrate assays and exploration targets remain distinct. Derived contained TREO retains its calculation and rounded-input provenance rather than becoming a source-reported measurement.
