## 入口與模組

| 路徑 | 審查判定與本輪處理 |
|---|---|
| `all`、`acquire` | 均呼叫 `census_acquisition`。前者串接 SQLite、Census 與排名，後者完成取件階段即回傳。靜態 PDF 及收據重播共用證據選入與下游流程。 |
| `discover`、歷史 `discovery.discover()`、歷史 `acquisition.refresh()` | 現行 CLI 為搜尋計畫；修正計畫讀取缺件時順帶寫取件紀錄的行為。兩個歷史函式仍有舊版測試或相容呼叫，與正式建置呼叫鏈分開。移除無現行呼叫者的 WebLink 可行性函式及兩個沒有有效執行路徑的 CLI 旗標。 |
| `rebuild --snapshot-lock` | 保留為歷史成果重建。直接讀取與驗證指定鎖，省去先從現行來源清單選一次再覆蓋的操作。 |
| 正式 Census 與 `export-summary` | 共用投影。獨立匯出已完成的整合資料庫時，使用同一執行的設定、快照、canonical membership 與取件狀態。對照資料庫紀錄的雜湊，原件依 SHA 確認。匯出保持 SQLite 唯讀。 |
| `recognize`、`pdf-extract` 和嚴格核驗 | 依用途提供文件候選、頁面證明與正式證據驗證。保留檢查工具與各層信任條件。 |
| GIS 品質、發布、排名 | 共用 CSV 讀取，解除 GIS 敏感度模組對發布模組的工具依賴。依一次匯出的工作範圍共用空間 JSON 解析，範本只處理當案欄位。 |

現行 live GitHub 工作由 `research.yml` 呼叫 `automated-build.yml`。歷史重播和測試使用前者的驗證工作。ASX 實驗、Round 3–5 和 locator 等 Git 分支仍有各自的工作區，現行正式建置未引用相鄰實驗工作區的程式或設定。此次精簡限於目前分支。 [CLI](../src/au_ree_v2/cli.py) · [GitHub Actions](../.github/workflows/research.yml)

## 自動化與本機依賴

- 已登錄來源的取件、SHA 驗證、抽取、入庫、Census 篩選和 MCDA 可由指令自動執行。live 工作安裝 Python 3.11、R 4.5.2、Tesseract 及語言資料。OCR 語言套件由未鎖版本的系統套件取得，精確重播宜另外保存版本與語言模型雜湊。
- 最新發布取件收據有 182 筆快照，連同原始回應共 188 個不同路徑。按 Git 追蹤路徑計算，123 個路徑未入庫。完整執行鎖另包含當輪產出的頁面記錄等衍生檔。精確重播需要已取得的原件與收據、核驗的設定版本及相容的 OCR 和 R 環境。
- 實際在空白來源工作區禁止網路連線後，以本機 SHA 套件驗證 420 筆選入來源和 209 筆取得紀錄。這是來源階段的乾淨環境測試。另以本機 SQLite 和已發布的 CSV 及面板成果核對後續投影。
- 新來源採用、截日前可得性、專案／礦床邊界和來源同名衝突仍需可審核證據。目前 live CI 使用固定研究截日。`research.yml` 的 push 觸發限定 `main`，另有 PR、手動和排程的工作條件。後續可把截日和來源套件版本納入版本化的建置輸入。 [離線重播說明](../README.md) · [CI 取得與驗證](../.github/workflows/automated-build.yml)

## 國際資料庫提案試跑

| 提案 | 對現行結果的測試 | 可帶入主結果的項目 |
|---|---|---|
| A 實體關係 | 有 14 筆文件支撐的 canonical alias 與 93 筆公司／開發商欄位。Mount Ridley 的 Mia 與 Blocks 1 & 2 保留不同估算範圍。 | 為公司角色、來源日期及身分審核提供查詢。有效期以有證據的關係為優先。 |
| B 資源估算 | 462 筆長格式觀測分為 68 組資源估算，Census 採用 38 組。該 38 組的 21 組含多個分類值。 | 以原件 SHA、statement、範圍、有效日及分類為查詢鍵。先驗證 Goschen Central、Mount Ridley 與 Nolans 的選用依據。 |
| C REE 組成 | 38 個選中組別中，有 36 組直接具備 TREO 基準的礦石量與品位。Splinter 的第 37 個完整估算有經查核的 Ce₂O₃→CeO₂ 換算，Wimmera 則保留部分觀測。 | 將換算式、輸入觀測與材料基準納入同一查詢結果。驗收應涵蓋直接值、轉換值及部分揭露。 |
| D 技術試驗 | 9 個案例有 8 組給料／基準／終點／尺度組合，唯一共用組合有 2 案。 | 先用查詢檢驗同給料、同終點與同尺度。成熟度和實際績效分別保留。 |

試跑以現行發布 CSV 和觀測表為基礎。優先在同一 SQLite 加強資源查詢與來源時序，再以可比較案例與排名敏感度驗收。 [資源觀測](../results/ree-project-census/current-20261119/resource_statement_observations.csv) · [排名證據](../results/ree-project-census/current-20261119/mcda_criterion_lineage.csv)
