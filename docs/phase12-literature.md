## 轉為可測試的研究規則

1. **先定位再驗證關係。** 候選保留原件 SHA、實際 PDF page、table row/column 或段落、Project/Deposit/sample/study scope。正確數字附在錯 scope、錯 basis 或錯日期角色仍不得升為正式觀測。LLM 可以提出候選；模型互相同意不能替代原頁核對。
2. **條件是觀測的一部分。** Recovery 保留 feed、product、REE/REO basis、試驗條件、scale、statistic 與樣本代表性。測試 mean、maximum、selected composite、DFS forecast、plant measurement 分組；不把同 Project 多列當獨立 n。
3. **資源與單位分開。** Resource/Reserve、global/deposit/zone、舊版/重發/更新、TREO/排除 Ce/含 Y/THM 各自定義。ppm→% 是單位換算；元素→氧化物另需明確化學式、化學計量與同一 denominator，不能只有元素名稱或百分比就轉換。
4. **以真實頁面負例評估。** 保留 glossary、forward-looking、公司財務及跨頁誤配樣本；分別計算 strict tuple precision/recall、FP/FN、scope accuracy、unit accuracy、定位完整率，註明文件數、sample n、標註範圍與未測版型。被正確攔下的錯誤候選是驗證層成果，不等於 parser 已能完整擷取。
5. **沿用現有 MCDA、明示條件。** 不新增 SMAA/ROR 正式引擎。將 preference、method、source-rounding、cohort 變化分開；沒有可信來源的不確定範圍維持未量化。對共同 Project 集合再比較，避免把新增樣本或缺漏選樣造成的變化歸為方法本身。

## T1 的科學結論

以上文獻支持將礦物學、製程性能與證據品質分開，尚不足以從製程名稱、單元數或零散 recovery 建立已驗證的通用 processing-complexity ordinal。上游正式 T1 與 V2 探索性 recovery_pct 的語意差異應維持；本階段不修改正式 T1、權重或 C1 定義。TC1/TC2 或其他明確同 endpoint 群組可繼續探索，但須保留工程預測／實測、共同 scope 及小樣本界線。任何將來替代 T1 的建議仍需操作化定義、代表性資料、codebook 一致性與排名影響比較。

文獻閱讀提高方法依據，不計為新增 Project 證據、數值、資料庫原件或 MCDA 樣本。
